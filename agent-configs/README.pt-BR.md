# Exemplos de Perfis de Agentes

Os arquivos TOML aqui são exemplos existentes para Codex/OpenAI, e não uma pilha obrigatória.
As regras do projeto em `AGENTS.pt-BR.md` e `docs/agents.pt-BR.md` aplicam-se a quaisquer provedores
e modelos locais. Model IDs/effort específicos são substituídos conforme o ambiente escolhido.

Ao realizar a migração, mantenha as responsabilidades das funções, limites de arquivos, verificações e economia
de contexto; adapte o formato de configuração e parâmetros ao cliente utilizado.
Não considere nomes idênticos de níveis de raciocínio como equivalentes entre modelos diferentes.
Não copie esses perfis automaticamente para o ambiente de outro provedor e não apresente
exemplos como uma integração já configurada. Não armazene chaves de acesso no repositório.

Alterações nesses exemplos não atualizam automaticamente os `.codex/agents` locais.
A configuração de um provedor/cliente específico é realizada separadamente a pedido do usuário.
