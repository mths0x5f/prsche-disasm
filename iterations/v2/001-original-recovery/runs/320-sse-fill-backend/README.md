The body loads a raw DWORD into XMM0 with MOVSS and broadcasts it with SHUFPS. It conditionally peels byte/word/DWORD/8-byte/16-byte stores based on the **updated** destination address and signed remaining byte count. Once 32-byte aligned, it emits two aligned non-temporal MOVNTPS stores per 32-byte block. It then uses MOVLPS for 8-byte blocks and scalar 4/2/1-byte tails. The C++ core uses SSE1 intrinsics for those exact store classes and exposes the original advanced EAX pointer. The canonical void `heap_fill_sse_005b0b00` adapter calls that same core. There are no new game data definitions, callee stubs or original machine bytes in the production source. It deliberately adds no production SFENCE, because no such instruction appears in the original body.
