Quatro execuções limitadas de bytes originais primeiro executam o trecho original de escrita do registro `004b0ff0..004b4b75` e então o consumidor completo, com pacotes de id controlado `0x10f` contendo 31/32/40/63 caracteres. Isso demonstra um caminho concreto de consumidor que admite strings mais longas e seus efeitos de memória. Não estabelece que um recurso de jogo distribuído ou uma sessão completa do jogo forneça tais pacotes. O trecho de escrita é indexado sob `004b0fa0`; sua entrada/vivacidade independente de função não é promovida por este experimento.
